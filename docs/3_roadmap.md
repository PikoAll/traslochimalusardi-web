# Roadmap

## Epic: qualita-sito
Rendere il sito verificabile e piu' solido (link, accessibilita', SEO, performance).
1. Controllo automatico dei riferimenti locali delle pagine HTML (script + test).
2. Correzione dei riferimenti rotti trovati dal controllo.
3. CI GitHub Actions che esegue i controlli su ogni PR.
4. Accessibilita' di base (testi alternativi, struttura, contrasto).
5. Coerenza SEO (sitemap, canonical, meta) con test.
6. Performance (caricamento differito immagini, dimensioni).

## Epic: post-rilascio
Manutenzione continua: segnalazioni dal campo, monitoraggio dei link, aggiornamento
della versione di cache busting e degli asset del template.

Le card sono sulla board GitHub del repo (milestone = epic).
